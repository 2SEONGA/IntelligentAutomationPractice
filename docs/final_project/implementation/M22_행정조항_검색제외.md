# M22 행정 조항 회사 자료 검색 제외

작성일: 2026-11-17  
상태: 완료 (세 RFP 판별 확인 + 상수도관 T2 라이브 비교).

## 요약

- **한 일:** T1이 요구사항으로 뽑은 보안서약서 문구, 지식재산권·산출물 귀속, 실적 인정 규칙, 참가자격 법조항을 판별해 T2 회사 자료 검색에서 제외하고, 제외 사유를 State(`company_retrieval_skipped`)에 기록했다.
- **결과:** 세 RFP에서 행정 조항을 판별했다(상수도관 12/32, CDW 7/91, 통합정보시스템 8/95). 상수도관 T2에서 행정 조항에 붙던 잡음 후보 9건이 사라져 전체 후보가 41→32건이 됐다. 적합도 50.0%는 그대로다. 테스트 16개 파일 통과.
- **남은 일:** 판별은 정규식 목록이라 새 서식 문구가 나오면 추가해야 한다. 적합도 계산(Agent 2 규칙 판정)은 여전히 행정 조항을 요구사항으로 센다. 이 수정은 검색 후보에만 적용했고, 점수 규칙 변경은 별도 결정이 필요하다.

## 판별 규칙 (`company_retriever.administrative_clause`)

| 사유 | 문구 예 |
|---|---|
| 보안서약서 문구 | "본인은 … 반납 및 파기", "나는 … 비밀을 유지", "당사는 … 내부정보", "'보안서약서'(별지 제16호)" |
| 지식재산권·산출물 귀속 | "지식재산권", "SW산출물의 반출을 요청", "공동 활용할 계획" |
| 실적 인정 규칙 | "입증책임", "합병 :", "분할 :", "발주한 경우 … 준용" |
| 참가자격 법조항 | "「소프트웨어진흥법」 제58조 … 신고를 필한" (M19 T1.5 참가자격에서 검증) |

- **요구사항 정의표 ID(SFR-001, QUR-002 등 `TECH-`가 아닌 3글자 코드)는 제외하지 않는다.** 표 행이 합쳐진 상세 텍스트에 다른 조항 문구가 섞여, 처음에는 QUR-002("산출물 완성도 관리")와 COR-001이 "산출물 … 반출"로 잘못 제외됐다.
- 기능 설명("검색된 자료에 대한 승인/반려 과정을 통한 반출 기능", CDW TECH-029)과 유사 실적 인정 범위(TECH-009/018)는 유지한다.

## 변경 내용

- `src/bid_review/rag/company_retriever.py`: `ADMINISTRATIVE_CLAUSES`, `FORMAL_REQUIREMENT_ID`, `administrative_clause(requirement_id, text)`
- `src/bid_review/rag/workflow.py`: 회사 자료 검색 전에 행정 조항을 걸러내고, `company_retrieval_skipped`(State에 추가)와 `company_retrieval_note`에 제외 건수를 기록한다.
- `tests/test_semantic.py`: 서약 주체별 표현, 정의표 ID 예외, 기능 설명 유지 사례를 검증한다.
