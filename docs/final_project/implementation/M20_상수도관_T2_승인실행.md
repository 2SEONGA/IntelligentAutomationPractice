# M20 상수도관 T2 승인 실행

작성일: 2026-11-17  
상태: 완료. T2 결과는 참고 분석이며, 최종 Go/No-Go는 사업본부장 결재에서 정한다.

## 요약

- **한 일:** 담당자 승인(M16)으로 상수도관 공고의 T2 회사 역량 분석을 실행했다. 실행 중 승인 감사 기록(`human_override`)이 LangGraph State에서 사라지는 버그를 찾아 고쳤다.
- **결과:** 분기는 `human_approved_company_matching_complete`. 적합도 50.0%이고, 요구사항 37건 중 부분 충족 23건, 확인 필요 14건이다. 21건에 회사 공개자료 RAG 후보가 붙었다. 테스트 15개 파일 통과.
- **남은 일:** 참가자격 ELIG-001~008은 공개자료로 증명할 수 없어 모두 확인 필요로 남았다(원본 증빙 필요). 웹앱 실행 폴더에서도 같은 승인을 하면 `core_review_audit.json`에 감사 기록이 남는다. 이번 실행은 CLI 경로다.

## 실행

- 입력: `data/input/AI 영상 기반 상수도관 노후도 분석 및 GIS 연동 소프트웨어 개발 용역.pdf`, 회사 자료 `data/company/company`, 공고문 `data/notice_attachments/R26BK01762350-000/notice.pdf`, 공고 R26BK01762350-000
- 승인: `review_decision=approved`, 검토자 `staff (사업기획 담당자)`, 사유에 M16 판정 3건을 기록
- 결과 파일: `outputs/langgraph_reviews/AI 영상 기반 상수도관 노후도 분석 및 GIS 연동 소프트웨어 개발 용역_T2승인_2026-11-17.json` (기존 기준선 파일은 덮어쓰지 않음)

## 결과

| 항목 | 값 |
|---|---|
| T1.5 상태 | `human_review` (승인으로 바뀌지 않음) |
| `human_override` | 검토자, 사유, `verification_status=human_review` |
| 적합도 | 50.0% (가중합 13.0 / 26.0) |
| 요구사항 37건 | 부분 충족 23 · 확인 필요 14 |
| RAG 후보가 붙은 요구사항 | 21건 (점수·자격 판정에 합산하지 않음, M10 원칙) |
| 참가자격 ELIG-001~008 | 모두 확인 필요 — 공개자료로는 입찰참가자격·실적 인정 여부를 확정할 수 없음 |
| 인력 항목 | 5건 (공개자료로 개인 경력 증명 불가) |

## 발견·수정한 버그: 승인 감사 기록 누락

`company_matching` 노드는 `human_override`(검토자·사유·T1.5 원래 상태)를 반환하지만, `BidReviewState`에 이 키가 없었다. LangGraph는 State 스키마에 없는 키를 버리므로 M5 이후 승인 사유가 결과에 저장되지 않았고, 검토 화면(`CoreReviewTab.tsx`)의 "승인 사유"도 비어 있었다. `BidReviewState`에 `human_override`를 추가하고, 재실행해 기록이 남는 것을 확인했다.
