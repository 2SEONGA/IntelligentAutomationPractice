# M26 공고 수집 키워드 누락 측정

작성일: 2026-11-17  
상태: 완료 (라이브 측정 30일 + 재현 7일). 측정 원본과 재측정 스크립트 보존.

## 요약

- **한 일:** 공고 수집이 공고명 키워드 5개(`정보시스템, 차세대, 클라우드, 인공지능, AI`)에만 의존한다는 점을 보고, 처음에는 의미 검색(RAG)으로 보완하려 했다. 그 전에 실제로 얼마나 놓치는지 측정했다. 같은 30일을 키워드 없이 전체 조회한 결과와 5개 키워드 조회 결과에 현재 규칙 필터를 똑같이 적용해 비교했다.
- **결과:** 규칙 통과 공고(검토 대상 + 확인 필요, 같은 사업 묶음 기준) **92건 중 54건(59%)을 키워드가 놓쳤다.** 놓친 공고 대부분은 회사 주력인 운영·유지관리 사업이다. 나라장터 API는 키워드 없는 기간 조회를 허용하고(30일 약 2분, 호출 약 20회), 분야 판정은 이미 조달분류 "ICT 서비스" 규칙이 하고 있으므로 **RAG 대신 "키워드 없는 전체 수집 + 기존 규칙 필터"로 보완하기로 했다.**
- **남은 일:** 웹앱 수집 전환(M27), Agent 3 과거 RFP 수집에 같은 방식 적용(M28). 의미 검색은 규칙 통과 공고의 우선순위 정렬이 필요해질 때만 다시 검토한다.

## 계기

- 발표 자료(RAG 활용) 준비 중 `config/notice_filter.yaml`의 `collect_keywords`가 5개로 한정된 것을 확인했다.
- 키워드를 고른 근거 문서는 없다. 3년치 낙찰 분석(`docs/go_no_go_checklist.md`)의 주력 유형(정보시스템 유지관리·차세대·클라우드 전환)과 과제 주제(AI)에서 나온 것으로 보인다.
- 설계 문서(`docs/superpowers/specs/2026-10-27-bid-review-web-v2-design.md` §269)에 따르면 수집 키워드는 "검색어일 뿐"이고 분야 판정은 조달분류로 한다. 그래서 키워드의 누락 영향은 확인된 적이 없었다.
- 의미 검색 보완을 검토했지만, 나라장터 API는 공고명 부분 일치 검색만 지원하므로 의미 검색을 하려 해도 먼저 넓게 받아야 한다. 그렇다면 "넓게 받기"만으로 해결되는지부터 재야 했다.

## 측정 방법

- 스크립트: `scripts/measure_collect_keyword_coverage.py` (읽기 전용, 웹앱 공고 저장소에 쓰지 않음)
- API: `BidPublicInfoService02/getBidPblancListInfoServcPPSSrch02`(용역), 7일 구간 단위, 웹앱과 같은 `_fetch`
- ① `bidNtceNm=""`(키워드 없음) 전체 조회 ② 5개 키워드 각각 조회 후 합침
- 두 결과 모두 현재 판단 기준의 `judge()`(금액·마감·분야·계약방법·참가조건)를 적용
- "같은 사업" = 공고명 + 수요기관이 같은 행(분할·재게시로 공고번호가 여럿인 경우 묶음)

| | 전체 조회 | 키워드 5개 |
|---|---|---|
| 수집 공고 | 17,449건 | 1,094건 (모두 전체 조회에 포함, 차집합 0) |
| 규칙 통과 (행) | 98건 | 39건 |
| 규칙 통과 (같은 사업 묶음) | **92건** | **38건** |
| 놓친 통과 공고 | | **54건 (59%)** |

판정별: 검토 대상 66행 중 41행, 확인 필요 32행 중 18행을 놓침. 키워드 결과 1,094건 중 1,055건은 규칙에서 제외됐다(키워드는 잡음도 많이 가져옴).

**재현(7일, 2026-11-10 ~ 11-17):** 전체 5,257건, 통과 38건 중 22건 누락(58%). 30일 결과와 비율이 같다.

- 공고명에 들어 있는 단어(놓친 통과 공고 기준, 중복 포함): 유지관리 27 · 운영 24 · 시스템 20 · 전산 12 · 유지보수 8
- 회사와 직접 관련된 예
  - **2027년 자치단체 공통기반 및 재해복구시스템 유지관리 (269.4억, 한국지역정보개발원)** — 체크리스트 해설의 "2024·2025·2026 연속 수주" 사업의 다음 해 공고
  - 한국지역정보개발원 사업 8건(통합지방재정·표준기록관리·주소정보·주민등록·사이버침해대응 등), 한국교육학술정보원 RISS·에듀넷 — 낙찰 분석의 핵심 고객 기관
  - 우체국금융시스템 유지·운영(708.5억), EBS 통합 운영(513.4억), 사법업무전산화 운영(210.2억)
- 키워드를 늘려도 남는 예: "지능형 AX 고도화 사업", "2026년 빅데이터 활용체계 고도화 사업", "지능형 무역투자 플랫폼 구축"

## 결정: RAG가 아닌 방법으로 보완

| 선택지 | 판단 |
|---|---|
| 의미 검색(RAG)으로 놓친 공고 찾기 | API가 의미 검색을 지원하지 않아 결국 전체를 먼저 받아야 함. 받은 뒤에는 규칙 필터로 충분 → **채택하지 않음** |
| 키워드 추가 (유지관리·운영·전산 …) | 끝이 없고 여전히 누락 → **채택하지 않음** |
| **키워드 없는 전체 수집 + 기존 규칙 필터** | 30일 약 2분·호출 약 20회, 분야는 조달분류 규칙이 이미 판정 → **채택 (M27)** |

의미 검색은 규칙 통과 공고(30일 약 90건)의 **우선순위 정렬**이 필요해질 때 다시 검토한다. 수집 누락 해결에는 쓰지 않는다.
