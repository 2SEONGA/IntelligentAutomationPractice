상태: 구현 및 원본 3건 기준선 실행 완료, 수동 정확도 평가는 남음  
작성일: 2026-11-11

## 요약

- **한 일:** T1 추출값(금액·참가자격·일정)을 원문과 대조하는 T1.5 검증기를 구현했다. 상태는 confirmed/retrieve_more/conflict/human_review.
- **결과:** 금액 단위·VAT·범위, 자격 조건 구조, 날짜 정규화·충돌 감지 체크와 citation을 기록. 3건 기준선 JSON 생성.
- **남은 일:** 정답 라벨 기반 정확도 평가, 일정 `not_applicable` 판정.

## 목표

기존 T1이 뽑은 값을 후속 회사 역량 분석(T2)에 넘기기 전 원문과 대조한다. 단일 confidence 값으로 뭉뚱그리지 않고 금액·참가자격·일정의 확인 항목, 출처 인용, 미해결 사유를 각각 기록한다.

## 구현 내용

- `src/bid_review/rag/verification.py`
  - 공통 상태: `confirmed`, `retrieve_more`, `conflict`, `human_review`
  - 각 검증 결과에 원문 chunk/page/section, 검색어, 개별 체크 결과와 미해결 질문을 보존
  - 금액: 원문 인용 일치, 원 단위 재변환, VAT 포함/별도/불명, 총액/연차 범위, 나라장터 배정예산·추정가격 교차 비교
  - 참가자격: T1이 추출한 조건별 원문 페이지 확인 및 키워드 포함 페이지 대비 추출된 페이지 누락 감지. 주체·공동수급 적용·예외·증빙 의미는 자동 확정하지 않고 사람 검토로 표시
  - 참가자격 개별 claim은 주체, 조건, 의무/허용/배제 효과, 단서/예외, 증빙 표식을 따로 검사한다. 단서가 있거나 핵심 구조를 인용에서 찾을 수 없으면 사람 검토로 보낸다. 이 검사는 구조 표식 확인이며 법률 해석이나 회사 적격성 판정이 아니다.
  - 일정: 수행기간, 제안서 시작·마감, 입찰 마감, 공동수급 협정서 마감 후보 확인, 동일 항목 상충 감지, 절대 날짜와 상대 기간 보존
  - 날짜 정규화 시 실제 달력 날짜인지 확인(예: 2월 30일은 유효값으로 만들지 않음)
- `src/bid_review/rag/corpus.py`: manifest에서 PDF 수와 나라장터 metadata 수를 각각 표시하도록 명확화
- `docs/final_project/implementation/M1_RAG_코퍼스_기초검색.md`: 본문 813개 + 공고 metadata 35개 = 총 848개로 집계 정의 수정
- src/bid_review/rag/retriever.py: PDF ID로 연결된 나라장터 공고번호를 조회해 T1 추출이 번호를 놓쳐도 교차 확인에 연결
- 기준선 표본 대조 후 누락 금액/일정 검색을 필드별 질의로 분리하고 all 매칭으로 좁혀 무관한 실적표·서식 chunk를 잘못 연결하던 사례를 줄임
- `outputs/t15_reviews/*.json`: 현재 3개 원본 PDF의 범주별 기준선 결과 저장

## 안전한 처리 원칙

- 원문 근거를 찾지 못한 값은 확인 완료로 승격하지 않는다.
- VAT 관계·금액 범위 또는 참가자격 의미가 충분히 분명하지 않으면 검토 대상으로 남긴다.
- 참가자격은 법적 의미의 자동 판정을 주장하지 않는다. 현재 자동화는 T1 추출 범위와 인용 근거 확인에 국한된다.
- T1 후보 누락은 별도 상태로 남긴다.
- RFP 예산이 VAT 별도이고 공고 API 배정예산이 약 10% 높으면 오류 충돌로 단정하지 않는다. 두 필드의 VAT 기준을 원문에서 확인하도록 사람 검토 처리한다. 적용 세율이나 과세 기준을 코드가 가정하지 않는다.
- 일정 후보에서는 `YYYY.MM.DD` 기입 양식을 실제 값에서 제외한다. 계약기간 표현이 달라도 같은 종료일을 나타내면 그 사실만으로 충돌 처리하지 않는다.

## 실제 원본 3건 기준선 실행

외부 LLM·Embedding API 없이 기존 `RFPExtractor`와 T1.5를 실행했다. 공고번호는 텍스트 추출값 대신 코퍼스의 PDF/공고 연결을 통해 찾았다.

| 원본 문서 | 금액 | 참가자격 | 일정 | 종합 |
|---|---|---|---|---|
| 상수도관 노후도 분석 | 사람 검토 | 사람 검토 | 추가 확인 | 사람 검토 |
| 임상연구정보검색시스템(CDW) | 추가 확인 | 사람 검토 | 추가 확인 | 사람 검토 |
| 통합정보시스템 고도화 | 추가 확인 | 사람 검토 | 추가 확인 | 사람 검토 |

상수도관 문서에서 RFP 107,000,000원(VAT 별도)과 나라장터 배정예산 117,700,000원의 차이를 발견했다. 최초 규칙은 이를 충돌로 판정했으나 VAT 기준 차이 가능성을 무시할 수 없어 사람 검토로 변경했다. 일정에서는 날짜 기입 양식을 실제 기간 후보로 오인하는 문제도 찾아 보정했다. 세 문서 모두 현재 자동 규칙만으로 T2를 진행할 검증 완료 상태는 아니다.

이는 기준선 실행과 규칙 보정이지 정확도 평가가 아니다. JSON 근거 인용과 claim을 원본 PDF와 수동 대조하는 작업은 남아 있다.

## 제한 및 미완료

- 3건을 실제 처리했으나 기준 정답(gold labels)과 인용을 사람 손으로 대조한 정확도 평가는 아직 하지 않았다. 단위/표 레이아웃/첨부 판본 차이를 포함한 판정 정확도는 미확인이다.
- 현재 일정 필드는 고정 목록이다. 원문상 해당되지 않는 항목과 실제 누락을 구분하는 명시적인 `not_applicable` 판정은 다음 보완 대상이다.
- 참가자격의 복합 조건(공동수급 구성원별 귀속, 실적 산식, 예외 조항)을 자동 확정하지 않는다.
- 공고 첨부 RFP의 실제 파일 본문은 아직 내려받아 색인하지 않았으므로 PDF와 나라장터 구조화 값 비교가 가능한 경우만 교차 확인한다.
