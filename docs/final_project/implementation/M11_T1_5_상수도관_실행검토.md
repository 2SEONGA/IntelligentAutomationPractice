## 라우팅 및 안전 확인

- 검증 상태가 `human_review`라 회사 자료 RAG 및 T2는 실행되지 않았다. 미승인 상태에서 T2로 넘어가지 않는 게이트 동작을 확인했다.
- 최초 자동 실행에서는 담당자 판정/승인이 없었으며, 이후 사용자가 아래의 항목별 판정을 제공했다. 이 판정을 T2 승인으로 간주하지 않았다.
- 이 실행은 실제 UI에 저장된 검토 건이 아니라 `run_bid_review` 직접 실행이다. 검토 탭 렌더링과 API를 통한 승인 후 결과 저장은 확인하지 않았다.
- 사용자가 원문을 웹에서 확인할 수 있도록 기존 웹 앱 실행을 시도했다. `npm run build`는 성공했으나, 현재 실행 환경이 `127.0.0.1:8000` 바인딩을 `operation not permitted`로 차단해 서버 시작은 실패했다. 로컬 파일을 기본 브라우저로 여는 동작도 이 환경에서 앱 연결 오류로 실패했다.
- 대체 수단으로 인용·판정 후보와 원본 PDF 페이지 링크가 있는 `M11_상수도관_T1_5_원문검토_미리보기.html`을 작성했다. 이 파일은 실제 앱의 저장된 검토 결과가 아닌 정적 미리보기다.
- API 근거 링크의 정확성 피드백을 반영해 G2B API 메타데이터 인용은 공고별 `notice_url`을 우선 링크하고, API 설명 페이지를 별도 필드로 보존하도록 코드/UI를 수정했다. 기존 인덱스의 공고별 URL은 `https://www.g2b.go.kr/link/PNPE027_01/single/?bidPbancNo=R26BK01762350&bidPbancOrd=000`이다.
- 위 URL 및 첨부 공고문을 현재 환경에서 실시간으로 다시 요청해 확인하지는 못했다. 기존 로컬 공고 수집본에는 `bidClseDt=2026-10-19 10:00:00`, 배정예산 `117700000`, 추정가격 `107000000` 및 공고문 첨부 URL이 기록돼 있다. 동적 API 재조회와 첨부 PDF 판독은 미완료다.
- 사업금액의 107,000,000원과 117,700,000원은 각각 RFP 사업금액(VAT 별도)과 공고 배정예산 후보로 추출됐다. 수치 차이가 세금 차이와 일치하더라도 문서의 항목 의미 및 기준은 담당자가 원문으로 확인해야 한다.

## 미해결 및 다음 단계

1. 나라장터 API에서 해당 공고의 구조화 필드와 첨부목록을 다시 조회한다.
2. API 배정예산의 공고별 출처를 확인하고, 첨부 공고문에서 제안서 제출기한을 확인한다.
3. 담당자가 T2 진행을 별도로 명시 승인하면 웹 검토 화면에서 회사 RAG 후보 노출과 저장 결과를 확인한다.

API 금액 출처와 제안서 제출기한 원문을 확인하고 사용자가 T2 진행을 명시 승인하기 전에는 T2를 진행하지 않는다.
