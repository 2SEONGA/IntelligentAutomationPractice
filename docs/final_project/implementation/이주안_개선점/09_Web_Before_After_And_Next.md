## 2. 더 수정·보완하면 좋은 부분

화면 빌드와 테스트 28개는 모두 통과한다. 아래는 오류가 아니라 **화면 내용이 바뀐 실행 흐름을 아직 따라가지 못한 부분**이다. 코드를 읽고 찾은 것이며, 1번은 실제 HWP 공고로 돌려서 확인하지는 않았다.

| 순위 | 위치 | 지금 상태 | 왜 문제인가 | 고치는 방법 |
|---|---|---|---|---|
| 1 | `CoreReviewTab.tsx` `isNotice`, `runs.py` `resolve_file`·`links.notice_pdf` | 공고문 인용·원문 열기가 `notice.pdf`만 인정 | HWP·HWPX 공고문으로 실행한 건은 공고문 인용이 RFP로 표시되거나 원문을 열 수 없음 | `isNotice`가 `notice.hwp(x)`도 인정. HWP는 브라우저에서 못 열므로 "내려받기" 링크로 표시 |
| 2 | `StageTracker.tsx`, `JobProgress.tsx` | 진행 화면이 "AGENT 2 · 병렬 역량 매칭 / AGENT 3 · 병렬 **시장 조사**", "역량 매칭과 시장 조사가 동시에 진행" | 실제 흐름은 T1 → T1.5 → 담당자 확인 → T2 → T3 → T4 순서. 시장조사는 없어짐. 발표·시연 때 화면과 설명이 어긋남 | 단계 이름을 "T1 RFP 분석·T1.5 검증 / T2 역량 매칭 / T3 유사 사업 / T4 보고서"로, 병렬 표시와 안내 문구를 순서대로 바꿈 |
| 3 | `RunResult.tsx` 탭 | 결과 탭 이름 "시장 조사" | 시장조사 기능이 없어졌는데 탭 이름이 남음 | "유사 사업·낙찰"로 이름 변경 |
| 4 | `NewReview.tsx` 업로드, `app.py` `_read_pdf` | 직접 올리는 공고문은 PDF만 받음 | 자동 수집은 HWP·HWPX도 받는데 직접 업로드만 안 됨(일관성) | 업로드도 HWP·HWPX 허용하거나, 최소한 입력칸에 "PDF만" 안내 |
| 5 | `notices.ts` `startNotes` | "받지 못한 첨부: … (PDF가 아니거나 내려받지 못했어요)" | 공고문은 이제 HWP도 받으므로 문구가 부정확 | "(받을 수 없는 형식이거나 내려받지 못했어요)"로 변경, 테스트 문구도 함께 |
| 6 | `CoreReviewTab.tsx` 유사 사업 | AI 재정렬 결과가 글자로만 덧붙음 | "분야 다름"이 눈에 잘 안 띔. 재정렬 실패(`t3_rerank_status`), 과거 사업 확장(`t3_expansion`), 새 공고 색인 추가(`rag_index_status`) 결과가 화면에 안 보임 | 재정렬 결과를 색 배지(관련=초록, 부분=노랑, 분야 다름=회색)로. 탭 위에 "AI 재정렬 사용/실패", "과거 사업 N건 추가됨" 한 줄 표시 |
| 7 | `Dashboard.tsx` | 카드 문구 "40억 이상(VAT 포함)"이 고정 글자 | 설정(`min_amount_vat_basis`)을 바꾸면 화면이 틀림 | 공고함처럼 `amountRule()`로 설정값을 읽어 표시 |
| 8 | `WEB_README.md` | 옛 설명(시장조사, `run.py` 실행) | 처음 보는 사람이 잘못 이해 | [`08_Data_Main_Merge_Web_Check.md`](08_Data_Main_Merge_Web_Check.md) 4장 표대로 수정 |

함께 고친 실행 문제(웹 점검 중 발견):
- `requirements-windows-py312.txt`에 `langgraph-checkpoint-sqlite`가 빠져 있어 Windows에서 담당자 확인(HITL) 실행이 시작되지 않았다(`pyproject.toml`에는 있음). 추가했다.
- 색인(`outputs/rag/`)이 없는 PC에서 웹 검토가 T1.5에서 `sqlite3.OperationalError`로 멈췄다. `rag/retriever.py`의 검색·공고번호 조회가 색인이 없으면 빈 결과로 넘어가게 했다.

확인: 화면 빌드 성공, 화면 테스트 29개 통과(담당자 확인 단계 테스트 1개 추가), 서버 테스트 `test_app`(HWP·HWPX 업로드 테스트 추가)·`test_hitl`·`test_runs`·`test_jobs`·`test_notices`·`test_app_batch`·`test_workflow` 통과. 서버 테스트 35개 파일 모두 통과(`test_app_v2`는 `.env` 키가 있어야 하는 검사 2개가 있어 임시 키로 확인). 시연 RFP(통합정보시스템)를 offline으로 실제 실행해 진행 화면과 결과 탭을 확인했고, HWPX 공고문을 함께 올린 실행에서 공고문 추출("공고문(HWPX) 추출 상태: 페이지 추출 완료")과 `notice.hwpx` 내려받기를 확인했다.
