# M10 Agent 2 요구사항별 RAG 연결 기록

작성일: 2026-11-16  
상태: 코드 반영 완료. M11에서 T1.5 런타임 분기를 확인했으며, 승인 후 T2 및 UI 노출 확인은 담당자 원문 검토 대기.

## 요약

- **한 일:** 회사 자료 RAG를 LangGraph T2 앞 노드로 연결하고, 요구사항별 검색 후보를 Capability 탭에 표시했다.
- **결과:** 검색 후보는 점수·자격 판정에 합산하지 않음. 인력 요구사항은 후보를 만들지 않음. 프론트 빌드 통과.
- **남은 일:** T2 승인 후 실제 화면 노출 확인.

## 목적

M9에서 만든 회사 자료 FTS 인덱스를 T1.5 승인 후 실행되는 LangGraph T2 역량 분석과 검토 UI에 연결한다. 검색 결과는 공개 근거 후보로 표시하며, 기존 매칭 점수와 참가자격 판정을 자동으로 바꾸지 않는다.

## 구현 내용

- `src/bid_review/rag/company_retriever.py`
  - 회사 JSON의 최신 수정 시각을 검색 DB와 비교해 인덱스가 없거나 오래되었으면 자동 재생성한다.
  - 검색 시 대상 법인을 `㈜아이티센엔텍`으로 제한하고, `record_type` 필터를 적용한다.
- `src/bid_review/rag/workflow.py`
  - T1.5가 확인되거나 사람이 T2 실행을 승인한 경우 `t2_company_rag_retrieval` 노드를 거쳐 T2로 이동한다.
  - 요구사항의 내용에 따라 수행실적/인증/재무/사업역량 자료 유형을 제한해 조회한다.
  - 인력 요구사항은 공개 회사 자료 검색으로 개인 경력이나 투입 가능성을 증명할 수 없어 검색 후보를 생성하지 않는다.
  - 검색 결과를 requirement ID에 연결하고, 출처·섹션·증거 수준·검증 필요사항을 포함해 State에 저장한다.
- `src/bid_review/models.py`, `src/bid_review/agent02_match.py`
  - `RequirementMatch.retrieved_candidates`에 RAG 검색 후보를 별도 저장한다.
  - 기존 규칙 기반 `status`, score, legal eligibility 판정에는 검색 후보를 합산하지 않는다.
- `web/src/components/tabs/CapabilityTab.tsx`
  - 요구사항별 검색 후보의 제목·발췌·출처·섹션·증거 수준·확인 필요사항과 HTTPS 출처 링크를 표시한다.
  - 최신 공시 원문 확인 대기 상태의 재무 후보에는 안내 배지를 표시한다.
  - 키워드 검색 후보는 적합도 점수·자격 판정에 자동 반영되지 않는다고 안내한다.
  - 조건부 표시를 명시적 삼항식으로 통일하고, 외부 출처 링크는 HTTPS만 새 탭으로 연다.

## 흐름

`T1 추출 → T1.5 검증 → (확인 또는 담당자 T2 승인) → 회사 자료 RAG 검색 → 결정론적 T2 매칭 → 검토 탭에 후보/출처 표시`

T1.5가 보류되고 사람 승인도 없는 경우 회사 역량 검색과 T2는 실행되지 않는다.

## 확인 상태 및 한계

- M9에서 생성한 기본 회사 FTS 인덱스에는 11개 record가 있으며, 신규/수정된 회사 JSON이면 실행 시 자동으로 다시 생성된다.
- M11에서 상수도관 RFP로 LangGraph 런타임을 실행했다. T1.5가 `human_review`로 끝나 회사 RAG/T2가 실행되지 않았고, 미승인 시 T2를 차단하는 흐름을 확인했다. 프론트엔드 build와 실제 화면 렌더링은 아직 확인하지 않았다.
- 코드 정적 검토에서 후보 검색 결과가 `retrieved_candidates`에만 전달되고 기존 점수·상태 계산은 그대로 유지되는 것을 확인했다. 실제 LangGraph 실행과 화면 렌더링 결과는 아직 확인하지 않았다.
- FTS5는 키워드 검색이며 의미 검색이 아니다. 임베딩 및 벡터 저장소 선택은 M4 결정 대기다.
- 회사 자료 후보는 LangGraph T2의 결정론적 `CapabilityMatcher`와 UI에 전달된다. 기존 별도 CrewAI live Agent 2에 검색 결과를 handoff하는 것은 미구현이다.
- 공개 자료만으로 실적 증명, 인증 유효성, 법인 귀속, 개별 직원 역량/가용성을 확정하지 않는다.
- 2026년 3분기 DART 원문 확인 전에는 2025년 연결재무를 최신자료로 표시하지 않는다.

2. 공식 2026년 3분기 보고서 원문을 확인하고 재무 근거를 갱신한다.
3. 임베딩 방식을 정한 뒤 FTS 기준선과 의미 검색을 비교한다.
