# M46 live 시장조사 B안 적용 — 웹의 모든 실행을 LangGraph로

- 작업일: 2026-11-25
- 결정: 담당자가 **B안(T3 색인의 낙찰 연결만 사용)**을 선택했다(M44 비교 후).

## 바뀐 것

| 구분 | 전 | 지금 |
|---|---|---|
| 웹 실행 경로 | "나라장터 시장조사"를 켠 live만 `run.py`(CrewAI 시장 Agent, 낙찰 실시간 검색) | **모든 웹 실행이 LangGraph** (T1 → T1.5 → 승인 → T2 → T3 → T4, live는 T4 뒤 CrewAI 브리핑) |
| 시장·낙찰 정보 | 옵션에 따라 실시간 검색 또는 색인 | T3 유사 사업에 연결된 색인 낙찰정보(`data/past_rfps/awards.json` 기준) |
| 화면 | "나라장터 시장조사" 스위치·안내 문구 | 스위치 제거, "유사 사업·낙찰 정보: 과거 사업 색인에서 함께 보여 줘요(실시간 조회 아님)" 안내 |
| API | `market_api` 입력, `/api/status`의 `market_available` | 둘 다 제거. 예전 클라이언트가 `market_api`를 보내도 무시되고 LangGraph로 실행 |

수정 파일: `web/jobs.py`(`build_command`의 `run.py` 분기 제거), `web/app.py`(옵션 검사·응답·상태), `web/langgraph_job.py`(설명), `web/src/{api.ts, types.ts, notices.ts, notices.test.ts, screens/NewReview.tsx}`, 테스트 `test_app.py`·`test_app_v2.py`·`test_jobs.py`.

## 남겨 둔 것
- `run.py`(CLI)와 CrewAI 시장 Agent 코드: 오프라인 일괄 실행·기존 테스트에서 쓴다. 웹에서는 더 이상 부르지 않는다.
- A안 실험 코드(`rag/live_awards.py`, `market_mode="live_awards"`): 기본 꺼짐. 낙찰정보서비스 키가 등록되면 다시 비교할 수 있게 둔다. 필요 없으면 지워도 운영에 영향 없다.

## 잃는 기능
- CrewAI 시장 Agent의 "사업명·수요기관으로 낙찰 실시간 검색". 다만 지금 키는 낙찰정보서비스에 등록돼 있지 않아 이 검색은 이미 실패하고 있었다(M44 실측 HTTP 403).
- 낙찰정보의 최신성은 색인 재수집 주기(지금 2026-11-17까지)를 따른다.

## 검증
- `test_app`, `test_app_batch`, `test_app_criteria`, `test_jobs`, `test_runs`, `test_workflow` 통과. `test_app_v2`는 화면 빌드 검사(Node.js 없음) 1건만 실패하고 나머지 11건 통과.
- 화면 코드(TypeScript)는 이 PC에 Node.js가 없어 빌드·타입 검사를 하지 못했다. `cd web && npm run build && npm test`로 확인해야 한다.
