## 2. 만든 도구

| 파일 | 역할 |
|---|---|
| `scripts/build_t3_threshold_sheet.py` (신규) | 최종 색인으로 시연 3건의 후보를 모아 판정표(`docs/final_project/회의_개선점/261118/T3_임계값_재평가_판정표.md`)를 다시 만든다. 열: ID, 시연 공고, 순위, 후보 사업(공고번호), 수요기관, 유사도, 0.70/0.80/0.90 포함 여부, **원문 근거(색인에 들어간 프로필 앞부분)**, 판정(빈칸). 사업명·수요기관은 실제 T3처럼 나라장터 공고 값을 쓴다. 후보 원자료는 `outputs/eval/t3_threshold_items.json` |
| `scripts/evaluate_thresholds.py --t3 <판정표>` (확장) | 판정 열(`관련`/`부분`/`무관`)을 읽어 임계값별 후보 수·정밀도·재현율·F1·**놓친 관련 사업**·**포함된 무관 사업**을 전체·사업별로 낸다. **미판정이 하나라도 있으면 "평가 미완료"로 표시하고 정밀도·재현율을 내지 않는다.** 판정이 다 차면 관측된 모든 점수를 임계값 후보로 훑어 세 값 밖의 최적 F1 값도 제안한다 |
| `tests/test_t3_thresholds.py` (신규) | 표 읽기, 지표 계산, 미판정 시 계산 차단, 세 값 밖 최적값 탐색 검사 |
| `past_projects.MIN_PROJECT_SCORE` | `config/settings.yaml`의 `past_projects.min_similarity`(0.70)에서 읽음. 값 변경 없음 |

관련 판정 기준(M25와 같음): `관련` = 업무 분야와 과업이 비슷해 참고할 만함, `부분` = 일부 업무만 겹침(관련으로 셈), `무관` = 분야가 다름.

## 4. Re-ranker 비교(점수만으로 분야를 못 가를 때)

이전 판정표(2026-11-19, 색인 102건)에서 상수도관 0.70 이상 10건이 대부분 분야가 달랐다(바다로시스템 0.773 등). 유사도가 "공공 SI 사업 일반"을 넓게 잡는 경향이다. 판정 결과에서 0.80·0.90도 무관 후보를 거르지 못하면 상위 10건에만 재정렬을 붙여 비교한다.
- 방법 A: 교차 인코더(로컬 모델 다운로드 필요, 이 PC에는 `sentence-transformers` 미설치).
- 방법 B: LLM 재정렬(질의 프로필과 후보 프로필을 함께 주고 관련도 0~2 점수). 사업당 10건 × 3건 = 30회, gpt-4.1-mini 기준 1회 약 2,000토큰 → 1센트 미만.
- 어느 쪽이든 사람 판정을 정답으로 같은 지표(정밀도·재현율·F1)로 비교한다. 키가 없어 이번에는 실행하지 않았다.

### 5-3. Re-ranker 비교 (`scripts/rerank_t3_candidates.py`)

같은 30건에 LLM 재정렬(gpt-4o-mini, temperature 0, 두 사업 프로필을 주고 관련도 0·1·2)을 붙였다. 입력 76,335 토큰, 약 1센트.

| 선택 규칙 | 후보 수 | 정밀도 | 재현율 | F1 |
|---|---:|---:|---:|---:|
| 유사도 ≥ 0.70 (현재) | 24 | 0.458 | 0.846 | 0.595 |
| **재정렬 ≥ 1** | 15 | **0.867** | **1.000** | **0.929** |
| 유사도 ≥ 0.70 그리고 재정렬 ≥ 1 | 13 | 0.846 | 0.846 | 0.846 |
| 재정렬 = 2 | 6 | 1.000 | 0.462 | 0.632 |

- 재정렬은 상수도관의 무관 후보 9건을 모두 0점으로 걸렀다(스마트도시만 1점).
- 판정과 30건 중 27건 일치. 다른 3건: 동강대 LXP(판정 부분, 재정렬 관련), 교직원공제회·부산대 데이터 플랫폼(판정 무관, 재정렬 부분).
- **주의:** 정답이 AI 대리 판정이라 같은 계열 모델끼리 비교한 셈이다. 재정렬 성능이 부풀려졌을 수 있으므로 담당자 판정으로 다시 확인해야 한다.

### 5-4. 판단과 제안 (운영 값은 바꾸지 않음)
- 0.70·0.80·0.90 중에서는 **0.70 유지**가 낫다. 0.80·0.90은 정밀도는 1.0이지만 관련 사업의 85%를 놓친다.
- 세 값 밖 최적(0.71)은 F1이 0.05 오를 뿐이라 바꿀 근거가 약하다.
- **제안:** 임계값은 0.70으로 두고, T3 상위 후보에 LLM 재정렬을 붙여 재정렬 0점(무관)을 결과에서 빼거나 "분야 다름"으로 표시한다. 실행마다 사업당 10회 호출(약 0.3센트)이 든다. 운영 반영은 담당자 판정 확인과 승인 뒤에 한다.
