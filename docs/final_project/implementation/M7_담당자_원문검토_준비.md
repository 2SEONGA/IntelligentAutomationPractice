# M7 구현 기록 — 담당자 원문 검토 준비

작성일: 2026-11-12
상태: 검토 자료와 직접 PDF 인용 표시 준비 완료. 담당자 판정 및 T2 실행은 미완료.

## 요약

- **한 일:** 담당자 원문 검토용 자료를 준비하고, 검색 일치가 없어도 T1 발췌와 PDF 페이지를 fallback citation으로 남기게 했다.
- **결과:** 세 공고 모두 참가자격 claim 인용 누락 0건, 자동 분기 human_review_required.
- **남은 일:** 담당자 판정(상수도관 일부는 M11에서 반영), T2 실행.

## 목적

LangGraph 결과를 담당자가 원문과 대조하기 전에 검토 화면의 근거 연결을 점검했다. RAG 색인에서 일치 chunk를 못 찾은 조건도 추출 문구와 PDF 페이지 링크를 잃지 않도록 보완했고, 화면에 해당 근거가 T1 추출본임을 표시한다.

## 변경 사항

- `src/bid_review/rag/verification.py`: 검색 chunk 일치가 없더라도 T1 원문 발췌와 PDF 페이지를 `EvidenceCitation`으로 제공한다. 이 fallback은 검색 일치로 오인하지 않도록 “T1 추출 인용 — 원본 PDF에서 담당자 확인 필요”로 표기한다. 기존 `RETRIEVE_MORE` 상태와 unresolved 질문은 그대로 유지한다.
- `web/src/components/tabs/CoreReviewTab.tsx`: citation 요약에 출처 섹션/근거 유형을 표시해 RAG 검색 chunk와 T1 fallback을 구분한다.
- 세 원본의 최신 LangGraph JSON을 재생성했다. 참가자격 claim에 인용이 없는 항목은 0건이다.

## 검토 시 유의할 점

- `confirmed`는 규칙 기반 자동 점검 상태이며 사람이 법적 요건을 승인한 의미가 아니다.
- `human_review`와 `retrieve_more`는 조건의 적용 대상, 증빙, 예외, 문서 검색 일치를 확인해야 한다.
- 범위 밖 후보도 분류 규칙의 오탐 가능성이 있으므로 표본 원문을 열어 제외가 타당한지 봐야 한다.
- 아직 사람이 승인한 사례가 없고 T2도 실행하지 않았다. 담당자 검토 사유를 임의로 기록하지 않았다.
