## 3. 주제별 정리

### 3.1 실제 자료로 끝까지 실행
- 상수도관 RFP: T1 → 나라장터 조회(공고문 SHA-256 일치) → T1.5(담당자 검토) → 승인 → T2 → T3 → 평가 → T4. AI 사전 권고 **보류**(적합도 50%, 사업 규모 1.07억 < 내부 기준 40억).
- 실행하면서 찾은 버그: 법인명 검사 상시 보류(기준명 `㈜아이티센엔텍(구 쌍용정보통신㈜)` vs 회사 자료 `㈜아이티센엔텍`), 웹 첫 검증의 나라장터 조회 상시 생략, 기관 공고번호 오탐(통합정보시스템이 승인 후에도 멈춤).

### 3.2 웹을 "검증 먼저" 구조로 일원화
- 전: 업로드 → CrewAI가 검증 없이 보고서 → (나중에 버튼) LangGraph 검증 → 보고서 2개.
- 후: 업로드 → LangGraph(T1 → 나라장터 → T1.5) → 확인 필요면 "검토 대기" 보류 보고서 → 승인 → 같은 실행 재개 → T4 보고서. live는 T4 뒤에 CrewAI Agent 4개가 검증된 결과만 받아 브리핑.
- 직접 업로드도 나라장터 공고번호를 입력하면 조회·교차검증한다.
- 남은 것: live의 "나라장터 시장조사"(낙찰 실시간 조회) 옵션만 기존 `run.py`.

### 3.3 체크리스트와 보고서 연결
- 체크리스트 K2(대기업 참여제한)·K3(공동수급·지역)를 T1.5에서 확인된 나라장터 값으로 자동 판정. 상수도관: K2 미충족(1.18억 < 40억, "대기업 참여 제한" 조항), K3 충족 → 1단계 **No-Go**.
- 보고서 개요에 나라장터 발주기관·입찰 마감(출처 표기), 보고서 검증에서 공고 조회값과 대조.

### 3.4 OCR·표 처리 (송하연 항목)
- 시연 RFP 176쪽: 다단 1쪽(조직도), 표 127쪽, 스캔본 0쪽 → LLM 요약 대신 **깨진 쪽만 OCR** + 표 병합 셀 복원.
- tesseract psm 4: 글자 일치율 0.314→**0.914**, 금액·날짜 보존 43%→**90%**. OCR 오탐 769→327쪽.
